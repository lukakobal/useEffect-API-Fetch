# React Day 30 – useEffect + API Fetch 🎣

A simple React project that demonstrates:

- `useEffect` for fetching data on initial render
- `useState` for storing the joke
- Fetching data from **https://api.chucknorris.io**
- Updating UI when the user clicks **Next joke**

## 🚀 Features

- Fetches a random joke when the app loads
- Displays the joke inside a styled card
- Button fetches a new joke instantly
- Clean and modern setup with `createRoot`

## 🧠 What I learned today

- How `useEffect(() => {}, [])` runs **only once**
- How to fetch data in React
- How to store API response using state
- Why effects are needed in real projects (APIs, listeners, timers…)
